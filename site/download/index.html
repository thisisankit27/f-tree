Ubuntu & Linux Your system

Take the .deb on Ubuntu, Debian or Mint. It is the one that needs nothing from you afterwards. The other two ask for a command first.

Finding the latest build…

One thing to expect on Windows. The installer is not code-signed, so Windows will stop it with “Windows protected your PC” and show the publisher as Unknown. Choose More info, then Run anyway. Every file is built in the open by GitHub Actions, and each has a checksum you can check on the page that follows your download.

Good to know before you install

Which Linux file should I take?

The .deb, unless you have a reason not to. It puts f-tree in your applications menu, updates cleanly, and is the only one of the three that can set up Chromium’s sandbox helper for you.

On Ubuntu 24.04 and newer an ordinary program can’t use the sandbox Chromium prefers, so it falls back to a helper that has to be owned by root. A package installer can arrange that; an archive you unpacked yourself can’t. The portable folder still works with one sudo chmod, printed on its download page. The AppImage is the one to avoid on those releases.

How is my tree kept safe?

Save a new tree once, choosing where it lives, and every change after that is saved as you make it. Each save goes through a temporary file first, so a crash or a full disk leaves the last good version in place. The app also keeps the last five versions of every tree. File › Show backups opens that folder.

Why does GitHub call the desktop build a pre-release?

The Android app looks for updates in the same list of releases and reads whichever GitHub calls the latest. Desktop releases are filed as pre-releases so that the latest is always an Android one. It’s a filing rule, not a verdict: the builds offered here are the stable ones.

Is there a macOS or iPhone version?

Not yet. Android, Windows and Linux are what is built and tested today.

How do updates work?

Both apps have two switches under Settings, off when you install: check for updates, and offer beta versions. Anything downloaded is checked against the SHA-256 GitHub published for it before you are offered it; if they disagree, nothing is installed.

Prefer not to install anything yet? Open a .ftree in the browser viewer. It never uploads your file.
